Nouveau personnage

Seul le prénom ou nom d’usage est obligatoire. Les rubriques vides restent discrètes. Les images peuvent être intégrées depuis ton ordinateur ou chargées par une adresse HTTPS.

Un nouvel univers

Ce nouvel univers réutilise l’un des sept thèmes. Son nom apparaît dans le menu et les formulaires.

Ton carnet de mondes

Crée une fiche, choisis son univers, puis complète librement les rubriques. « Modifier la fiche » permet ensuite de changer chaque texte, lien, image ou événement et de réorganiser les listes avec les flèches.

Les changements sont enregistrés lorsque tu cliques sur « Enregistrer la fiche ». La sauvegarde appartient à ce navigateur et à cette adresse de fichier. La navigation privée, l’effacement des données ou le déplacement du fichier peuvent la rendre indisponible. Exporte régulièrement une copie JSON ; elle contient aussi les images importées.

L’import fusionne les données : les identifiants identiques sont remplacés par ceux de la sauvegarde, les autres sont ajoutés. Une confirmation précède cette opération.

Les images importées sont réduites à 1 600 pixels maximum pour préserver la place. Les images distantes et YouTube nécessitent Internet. Les liens YouTube s’ouvrent dans un nouvel onglet.

Les deux premières fiches sont des exemples vides à personnaliser. Aucun contenu de personnage n’est inventé.
